WhatsApp otomatik gönderim

Meta WhatsApp Cloud API. Token ve Phone Number ID girin. Açıkken durum değişiminde mesaj otomatik gider; kapalıysa eski gibi manuel WhatsApp linki çıkar.

Token istemcide ayarlar tablosuna yazılır; Edge Function whatsapp-gonder ile gönderilir. Daha güvenli için Supabase Secrets: WHATSAPP_TOKEN, WHATSAPP_PHONE_ID.

Müşteri mesajları

Her aşamada müşteriye gidecek mesaj. Aşamayı değiştirince açık olan aşamalarda mesaj hazır gelir. Kullanabileceğiniz alanlar: {ad} {no} {sube} {tarih} {kalemler} {toplam} {odenen} {kalan} {teslim}

Terzi birimlerinde "Hazır" aşamasında 5. mesaj kullanılır.

Veritabanı bağlantısı (Supabase)

Supabase > Settings > API Keys sayfasından Project URL ve Publishable key'i alın. Gizli (secret) anahtarı yazmayın. Kaydedince uygulama yenilenir. Bu cihazda kayıtlı ayar varsa o kullanılır, yoksa index.html dosyasındaki ayar; diğer cihazlar dosyadaki ayarı kullanır.
